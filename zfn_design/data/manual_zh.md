# ZFN 设计工作台 · 程序使用说明书

版本 0.7.0 · 2026-11-18

## 1 这是什么

一套 ZFN（锌指核酸酶）设计工具。输入一段 DNA 序列，它做四件事：

- **S1 DesignScore**：扫出候选位点，给每个设计打六项综合分，排序出 all-target 报告。
- **S2 Target filter**：可选。把候选放回全基因组，落在重复序列里、或在基因组里出现 ≥3 次的，整条剔除。
- **S3 Off-target Score**：可选。对 Design_score 前 N 个设计做全基因组脱靶扫描，算 burden。
- **S4 Fusion design**：给选中的设计接上效应结构（VP64 / KRAB / FokI），出融合蛋白序列和人源化 CDS，附一张合成订单表。

所有计算在本机或实验室服务器上进行，序列不上传第三方。

## 2 访问方式

### 2.1 网页版

浏览器打开：

- 本机：`http://127.0.0.1:8797/`
- 公网示例：`https://zfn.mobilome.cn/`（本组部署）

页面左上角有 `EN / 中文` 按钮，切换整页语言，选择会记住。

### 2.2 本机启动

```bash
python -m zfn_design gui --port 8797 --no-browser
```

`--out-root` 可指定结果目录，默认 `<项目>/out/gui/`。

## 3 界面地图

左栏是输入，右栏是结果。

- 输入区从上到下：DNA 序列框、构型、spacer 长度、指头阵列、参数、Target filter（折叠）、两个按钮。
- 两个按钮：**Design Score（S1 + S2）** 和 **Off-target Score（S3）**，各带一条进度条。
- 结果区：统计卡、设计清单、Off-target 表、S4 面板、文件下载链接。

## 4 五步上手

### 4.1 粘序列

把 DNA 粘进左上大框。纯文本或 FASTA 都行；FASTA 的头行会当作序列名。点「载入示例」可以看一段能跑通的序列。

### 4.2 （可选）选基因组做 Target filter

展开「Target filter · 全基因组重复过滤」，在第一个下拉里选基因组 FASTA（例如 `GRCh38.p14.fna`），第二个下拉可选 RepeatMasker 注释（`.out` 或 `.bed`）。

选了基因组，过滤就按全基因组口径：

- 候选 motif 的任何落点压在 RepeatMasker 注释区 → 整条剔除；
- 候选 motif 在基因组里出现 ≥3 次（含反向互补）→ 整条剔除；
- 被剔除的位点**不参与打分**。

不选基因组，就只做 DesignScore，不碰重复序列。

### 4.3 点 Design Score

结果区出现统计、候选表、设计卡片，按 Design_score 从高到低排。跑完可以「整包下载 (zip)」。

不带基因组：十几秒。带 GRCh38：约 3 分钟（扫 33 亿碱基）。

### 4.4 （可选）点 Off-target Score

前提：**只有做过 Target filter 的作业才能跑 S3**。没过滤的作业会被拒绝并说明原因。

输入 Top N（默认 10）与每侧错配上限（默认 2），点按钮。它会读上一次作业的 `report.json`，对 Design_score 前 N 个设计做全基因组扫描。

结果给两个分：`off-target score`（0–100，越高越好）与 `burden`（越小越好）。两者**并列展示，不加进 Design_score**。

每个设计扫一遍全基因组约 1–2 分钟。

### 4.5 （可选）点 S4 生成融合蛋白与 CDS

在结果区的「④ S4 · Fusion design」面板里：

- **Top N**：取前几个设计（默认 3）；
- 勾选效应结构：VP64（激活）、KRAB（抑制）、FokI（核酸酶），可多选；
- 点击「生成融合蛋白与 CDS」。

产物有四样：融合蛋白序列、人源化 CDS、订单表、重打过的 zip。S4 只读这次作业的 `report.json`，不重算 S1–S3。

## 5 参数表

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 构型 | 按指头库可用架构 | 单体型（激活/抑制）或组合型（成对核酸酶） |
| spacer 长度 | 5–7 | 只对组合型有意义；单体型忽略 |
| 指头阵列 | 三指 | 三指读 9 bp，六指读 18 bp；其他指数走通用拼接骨架 |
| 每靶点数 | 3 | 同一候选位点出几个设计 |
| 最多处理位点 | 20 | 打分前最多保留的候选数 |
| 每侧最大错配 | 2 | 脱靶判定的错配上限（0–3） |
| Top N（S3） | 10 | 参与脱靶扫描的设计数 |
| 每侧错配上限（S3） | 2 | 扫描时的错配上限 |
| Top N（S4） | 3 | 参与融合设计的设计数 |

## 6 输出文件

一次作业一个目录，默认在 `<项目>/out/gui/<时间戳>_<序列名>_<短码>/`。

| 文件 | 内容 |
| --- | --- |
| `report.html` | 完整报告，浏览器打开 |
| `report.json` | 结构化结果，下游脚本读这个 |
| `sites.tsv` | 候选位点表 |
| `designs.tsv` | 设计表（含分数明细） |
| `offtarget_genome.tsv` | S3 结果（跑过才有） |
| `fusions.json` | S4 条目（跑过才有） |
| `proteins.tsv` | 融合蛋白（一链一行） |
| `cds.tsv` | CDS 明细（含起始/终止密码子、GC、位点） |
| `cds.fasta` | CDS 序列，可直接下单 |
| `order_form.csv` | 合成订单表 |
| `zfn_bundle.zip` | 以上全部打包 |

## 7 结果怎么读

**Design_score**（0–100）是六项加权：指头证据强度、三联体质量、GC 平衡、指头多样性、序列复杂度、自身互补风险。A ≥ 85，B ≥ 70，C ≥ 55。

分只说明「按公开设计规则看更像靠谱位点」，**不是活性预测**。

**burden** 是脱靶负担：每个近似位点按错配数加权（0 错配 1.0、1 错配 0.25、2 错配 0.06、3 错配 0.015、4 错配 0.004）后求和。`off-target score = 100 − 25 × burden`，下限 0。命中数触到上限（500）时，burden 是下限，界面标「（下限）」。

**CDS 状态**：

- `CDS 合格`：以 `ATG` 起、以终止密码子止、GC 与位点检查通过；
- `需复核`：能出序列，但有红旗（例如未算脱靶、含未验证元件）；
- `缺元件`：缺可靠序列，不出 CDS。

红旗要一条条看，不能跳。

## 8 命令行

```bash
# 只做 S1（可选 S2：加 --genome / --repeats）
python -m zfn_design run --seq "ACGT..." --out out/run1

# 带全基因组过滤
python -m zfn_design run --seq input.fa --genome refs/GRCh38.p14.fna \
    --repeats refs/GRCh38.p14.rm.out --out out/run2

# S4：对已有结果目录做融合设计
python -m zfn_design fusion out/run2 --top 3 --arch single_activator paired_nuclease
```

可用子命令：`run`、`fusion`、`scan`、`library`、`info`、`gui`。

## 9 报告与下载

网页上每个作业下方有文件链接，「整包下载 (zip)」一次拿全部。

`report.html` 是小节编号的完整报告：输入、Target filter、指头库、候选位点、三联体、设计、Off-target score、融合、权重。

## 10 常见问题

**点了没反应？** 看进度条。没动说明请求没发出去；浏览器控制台看 `POST /api/run` 的状态。

**提示「先选基因组」？** S3 与 Target filter 必须有基因组。选 FASTA 再跑一次 Design Score。

**提示「只有通过 Target filter 的候选才能做 Off-target Score」？** 上一轮没走过滤。勾上基因组重跑。

**跑得慢？** 带 GRCh38 的 S1+S2 约 3 分钟；S3 每设计 1–2 分钟。都是单进程，别同时点两次。

**设计数为 0？** 候选全被过滤，或指头库缺三联体。看报告的「缺口次数」。

**CDS 缺元件？** 那条融合蛋白里至少一个元件没有可靠序列。在 S4 的「元件 JSON」里填入，或换架构。

**能直接下单吗？** 序列可以，活性不行。任何设计进实验室前必须 T7E1 或扩增子深度测序验证。

## 11 限制与免责

- 打分基于公开文献整理的规则，不预测活性；没有做结构建模。
- 基因组过滤只认 RepeatMasker 注释与拷贝数，未覆盖没注释的低复杂度区。
- 脱靶是按半位点相似度的近似扫描，不是切割概率。
- 指头骨架来自 1AAY 派生模板，模块之间的连接与取向没有结构证据。
- 密码子优化避开了常见酶切位点与同聚物，但没有做剪接位点检查。
