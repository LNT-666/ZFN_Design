### 1.1 RepeatMasker 注释（用户自备，不进仓库）

全基因组模式需要重复序列注释，本仓库**不附带**任何基因组或注释文件（体积太大、且各自有许可）：

| 要什么 | 从哪来 | 用法 | 许可/注意 |
|---|---|---|---|
| 重复注释 `*.out` / `*.bed` | [RepeatMasker](https://www.repeatmasker.org/) 输出，或 UCSC `rmsk.txt` 转 BED；Dfam / Repbase 库 | `--repeats rm.out` | RepeatMasker 本身开源（GPL/Artistic）；**Repbase 库对商业使用有限制**，Dfam 为 CC0 系。发表时请按你实际用的库引用 |
| 基因组 FASTA | UCSC / Ensembl / NCBI（GRCh38、mm10…） | `--genome GRCh38.fa` | 各站点有各自的使用条款；GRCh38 由 Genome Reference Consortium 维护 |
| 目标区域 BED | 自己从 GTF 抽启动子/外显子，或 ENCODE cCREs | `--regions promoters.bed` | 看你用的注释来源 |

> 为什么必须过滤：重复区（Alu/LINE/卫星）在基因组里有成千上万个近似拷贝，设计在里面的 ZFN 不是单靶点。工具除了按注释剔除，还会把"同一段序列第二次出现"的候选标成 `multi_copy`——注释漏掉的拷贝靠这一层兜住。


### 1.2 1AAY 的引用

条目名 `ZIF268 ZINC FINGER-DNA COMPLEX`，主引用（RCSB `rcsb_primary_citation` 实读）：

```bibtex
@article{elrod1996zif268,
  title   = {Zif268 protein-DNA complex refined at 1.6 A: a model system for
             understanding zinc finger-DNA interactions},
  author  = {Elrod-Erickson, M. and Rould, M. A. and Nekludova, L. and Pabo, C. O.},
  journal = {Structure},
  volume  = {4},
  number  = {10},
  pages   = {1171--1180},
  year    = {1996},
  doi     = {10.1016/S0969-2126(96)00125-6},
  note    = {PMID 8939742; PDB 1AAY; 精修自 1ZAA}
}
```

> 实践建议：正文里写"骨架与三条种子识别螺旋取自 PDB 1AAY（Zif268–DNA 复合物，1.6 Å，Elrod-Erickson 等 1996）"，并给出 PDB 链接即可。**不要**把 1AAY 的整套坐标文件塞进仓库。

## 2. 需申请的数据（本地已接入，但**不作为可再分发数据**）

### 2.1 Princeton B1H 数据集（Persikov 2015）——**需自行申请，仓库不含**

| 项 | 内容 |
|---|---|
| 内容 | 全部 64 个 3 bp 靶点 × 每个指位（F2/F3）的结合谱，>160,000 个 domain–DNA 互作 |
| 入口 | <https://zf.princeton.edu/b1h/download.html> |
| 获取方式 | **必须填表**：Name / Affiliation / Email，选 dataset = `F2 union` 或 `F3 union`（表单 POST 到 `../../cgi-bin/b1h/download.cgi`） |
| 费用 | 免费，**非商业**用途 |
| 当前状态 | 本仓库**不含**该表。仓库只带 3 条 1AAY 种子库（`data/finger_library_seed.csv`） |
| 再分发 | **不可以**。对外发布的包只带种子库；用户申请到数据后，按 `data/finger_library/README.md` 放到 `zfn_design/data/finger_library/finger_library_b1h.csv`（程序会自动优先使用），或用 `library import-b1h` 转成 csv 后 `--library` 指定 |
| 本项目的处理 | **不**脚本绕过申请表单（尊重作者的非商业申请机制）；提供导入器 |
| 引用 | Persikov AV, Wetzel JL, Rowland EF, Oakes BL, Xu DJ, Singh M, Noyes MB. *Nucleic Acids Res.* 2015;43(3):1965–1984. doi:[10.1093/nar/gku1395](https://doi.org/10.1093/nar/gku1395) |

**文件格式**（导入器按此实现，两种写法都吃）：每个三联体 × 每个指位一个文本文件（官方命名 `GCG_amino_acid_union_cut.txt`），每行 = 识别螺旋在 **−1, 1, 2, 3, 5, 6** 六位（官方为 6 残基连写，如 `RRDTTN 0.0069884`，频率已按三联体归一）+ 频率。**位置 4 数据里没有**（该位不接触 DNA），导入时默认补 `L`（可用 `--pos4` 改），并在 `notes` 里写明"未测"。

一个已验证细节：拿到的数据里**不存在**天然 Zif268 的三个 6-mer（`RSDHTT` / `RSDETR` / `RSDEKR`）——这是设计的组合库，不含天然序列，不是格式错误。

**导入命令**：

```bash
python tools/build_library.py --f2 ./F2_union --f3 ./F3_union --top-n 8   # → data/finger_library_b1h.csv
zfn-design library info                                                   # 应显示 1027 条 / 64-64
zfn-design library import-b1h ./F2_union --split F2 --top 8 --out f2.csv  # 只导单个数据集时
zfn-design run --fasta gene.fa --out out/
```

## 7. 复现本文件的核验

```bash
# 复核 PDB 序列（种子库每一条都必须出现在这条序列里）
curl -s https://www.rcsb.org/fasta/entry/1AAY

# 复核文献元数据
curl -s 'https://www.ebi.ac.uk/europepmc/webservices/rest/search?query=DOI:10.1093/nar/gku1395&format=json'
```
