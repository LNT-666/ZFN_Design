这一页把 zfn_design 的流水线摊开给你看：点任意阶段看它的输入、输出和失败模式； 把序列贴进下面的框，可以直接在浏览器里跑一遍同样的计算——不用装 Python。

注意：这一页只演示组合型（成对 ZFN，左半位点 + spacer + 右半位点）。 单体型（ZF-TF）与六指阵列请用 python -m zfn_design gui 或命令行 --architecture / --fingers。

先说清楚这一页是什么。 它是流水线的「会动的说明书」，不是活性预测器。 分数只表示「按公开设计规则看起来更像靠谱位点」，与实测亲和力、切割效率没有定量关系。 任何设计进入实验前，必须过 T7E1 / amplicon 深度测序验证，并做 in silico 脱靶复核与至少两次独立重复。

这个演示做了什么

  • 真·同一套规则：指头库、骨架模板、打分权重、融合元件都直接从仓库的 data/*.json 读进来。
  • 真·同一套算法：JS 逐行对照 targets.py / designability.py / build.py / score.py / offtarget.py。
  • 不是把 Python 结果写死在页面里——换一段序列，数字会跟着变。
  • 反过来，python -m zfn_design run 才是权威实现，输出报告、TSV、融合稿都是它生成的。
